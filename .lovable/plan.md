# NSAGPT AI Answer Formatting

## Goal
Make AI replies easy to read instead of showing raw Markdown symbols such as `**`.

## Changes
- Render AI replies as properly formatted rich text.
- Display headings, bold and italic text, numbered and bulleted lists, quotes, links, and code cleanly.
- Improve spacing, line height, word wrapping, dark-mode contrast, and Urdu/right-to-left presentation.
- Keep user messages as plain text and preserve the current chat behavior.

## Verification
- Test a reply containing headings, bold text, lists, links, and code.
- Check the AI screen on desktop and mobile, including dark mode.

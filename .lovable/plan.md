# 10 Additional Question Paper Styles

## Goal

Keep all five existing paper styles unchanged and add ten polished, clearly different styles. Teachers can preview any style, customize it, edit question text in preview, and export the same design to print/PDF.

## New styles

1. **Minimal Ledger** — thin rules, left-aligned identity, compact ledger-like details.
2. **University Bluebook** — academic masthead, understated blue accents, wide reading rhythm.
3. **Scholar Serif** — book typography, ornamental double rules, centered formal header.
4. **STEM Technical** — structured grid, monospaced detail labels, crisp technical sections.
5. **Modern Ribbon** — strong side-accent headings and clean sans-serif question layout.
6. **Board Official** — traditional examination-office layout with boxed candidate details.
7. **Journal Editorial** — editorial masthead, two-level hierarchy, refined section lines.
8. **Clean Worksheet** — friendly classroom worksheet layout with clear answer spacing.
9. **Executive Assessment** — restrained institutional header, bold section numbering, premium spacing.
10. **Monochrome Archive** — printer-friendly black-and-white archival layout with heavy rules.

## Implementation

- Extend the style selector from 5 to 15 options without changing existing style keys or presets.
- Give each new style its own structural treatment for header, information grid, part banners, section headings, question rows, options, borders and spacing—not only a color change.
- Keep all current customization controls working across every style: accent color, heading/body font, font size, density, divider, logo size and alignment.
- Preserve marks calculation, Attempt Any rules, inline numbering, English/Urdu behavior, preview editing, logo fitting and shared preview/PDF output.
- Keep saved papers compatible; existing saved style choices continue rendering exactly as before.

## Verification

- Visually inspect all 15 styles using the same sample paper.
- Confirm the original five are unchanged.
- Confirm every new style is visibly distinct, A4-safe, editable in preview and identical in print/PDF.
- Check marks totals, pagination, logo sizing and mobile style selection.
